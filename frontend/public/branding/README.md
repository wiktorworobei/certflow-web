# ZNAQ

Платформа для работы с декларациями, документами сертификации и маркировкой.

**Точность имеет знак.**

Знак объединяет квадратную печать, вырезанную букву Z и диагональный хвост Q. Он используется самостоятельно в иконке браузера и компактном меню, а вместе с надписью ZNAQ — в основном логотипе.

## Файлы

- `znaq-logo.svg` — основной логотип на светлом фоне; вся надпись переведена в векторные контуры.
- `znaq-logo-light.svg` — одноцветная светлая версия на тёмном фоне.
- `znaq-logo-on-dark.svg` — лаймовый знак со светлой надписью.
- `znaq-symbol.svg` и `znaq-symbol-lime.svg` — отдельный знак.
- `znaq-brand-sheet.svg` — лист айдентики с вариантами логотипа и палитрой.
- `Inter-LICENSE.txt` — лицензия шрифта Inter, использованного для надписи.

## Визуальная система

| Роль | Цвет |
| --- | --- |
| Угольный | `#142119` |
| Сигнальный лаймовый | `#D6FF5F` |
| Матовый светлый фон | `#F3F5F0` |
| Основной текст | `#18251D` |
| Вторичный текст | `#56645B` |

Лаймовый акцент выделяет главное действие и фирменную графику. Рабочие таблицы и формы используют спокойные поверхности и контрастный текст. Цвета предупреждений, ошибок и статусов сохраняют отдельное значение.

Интерфейс использует Inter 400–800. Основные поверхности имеют радиус 14–18 px, элементы управления — 8–10 px. Иконки, поля, таблицы и диалоги строятся на общей системе токенов для MUI и модулей Radix.

Минимальная ширина отдельного знака — 20 px, полного логотипа — 120 px. Вокруг него оставляется свободное поле не меньше четверти высоты знака. Логотип нельзя растягивать по одной оси, перекрашивать в цвета статусов или размещать на фоне с недостаточным контрастом.

Фирменная палитра выбирается в «Настройки → Оформление → ZNAQ». Ранее выбранные пользователем палитры и режимы продолжают работать.
