# ZNAQ → ФГИС

Расширение Manifest V3 для Microsoft Edge, Google Chrome и Яндекс Браузера на компьютере. Заполняет доступные поля **уже открытого** черновика на `https://srd.fsa.gov.ru` из сохранённой декларации ZNAQ. Для работы требуется однократная установка в каждом браузере и профиле.

## Установка

1. В карточке декларации нажмите **Перенести в ФГИС**, скачайте расширение и распакуйте ZIP в постоянную папку. В локальном репозитории можно сразу выбрать папку `browser-extensions/fgis`.
2. Откройте `edge://extensions` в Edge, `chrome://extensions` в Chrome или `browser://extensions` в Яндекс Браузере.
3. Включите режим разработчика, нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
4. Откройте вкладку ZNAQ, нажмите значок расширения и **Подключить эту вкладку ZNAQ**. Разрешите доступ к адресу программы. Для другого адреса ZNAQ подключение выполняется отдельно.
5. В том же браузере и профиле самостоятельно войдите в кабинет ФГИС, создайте или откройте нужный черновик.

После обновления расширения обновите открытые вкладки ZNAQ и ФГИС. Не удаляйте папку установленного расширения.

## Перенос

Сохраните декларацию, нажмите **Перенести в ФГИС**, выберите нужную вкладку кабинета и нажмите **Заполнить открытый раздел**. Перед переносом ZNAQ повторно получает сохранённую версию с сервера. Несохранённые изменения, устаревшая версия, отсутствие прав редактирования и статусы вне Draft/InReview/Ready запрещают перенос.

Расширение сопоставляет поля по точным подписям и разделам. Наименование и ИНН заявителя и изготовителя различаются по контексту. Неоднозначные поля пропускаются. Если подписи отличаются, нажмите **Сопоставить поля**, выберите реквизит в панели кабинета, нажмите **Указать поле** и нажмите на соответствующее поле формы. Затем вернитесь в ZNAQ и повторите заполнение. Привязки сохраняются для маршрута формы; при изменении подписи, типа или контекста требуется повторное сопоставление.

После перехода в следующий раздел кабинета повторите перенос. Уже совпадающие значения не меняются. Отличающиеся существующие значения сохраняются и попадают в отчёт. Обычный список заполняется только при точном однозначном совпадении существующего варианта. Поля поиска по справочникам, создание повторяемых блоков протоколов и прикрепление файлов выполняются вручную. Для нескольких протоколов можно сопоставить каждый уже добавленный блок отдельно.

Переносятся структурированные реквизиты: заявитель, изготовитель, продукция, схема и вид декларации, регламенты, даты, дополнительные сведения, нормативное основание, стандарты и реквизиты протоколов. Ручные печатные формулировки, тексты приложений и внутреннее название карточки не подставляются в произвольные поля.

Проверьте весь черновик в кабинете. Расширение не нажимает кнопки сохранения, отправки, регистрации или подписи. Сам сайт может сохранять изменения при редактировании полей. Статус декларации ZNAQ не меняется. Отчёт описывает заполнение интерфейса и не подтверждает сохранение сервером ФГИС или регистрацию документа.

## Данные и разрешения

Расширение работает с выбранным адресом ZNAQ и доменом `srd.fsa.gov.ru`. Доступ к ZNAQ запрашивается только при подключении через значок. Проверяется точный origin вкладки, включая порт. Пароли, cookie, токены ZNAQ, закрытые ключи и PIN не передаются расширению. Сведения декларации передаются локальными сообщениями браузера и используются для заполнения формы; отдельно во внешние сервисы расширение их не отправляет.

В локальном хранилище расширения остаются адреса подключённых программ и сопоставления полей (селекторы, подписи и контекст). Значения деклараций в хранилище не записываются. При открытой панели сопоставления они находятся в памяти вкладки до закрытия панели или перезагрузки.

## Проверка и ограничения

`npm run test:fgis` в `frontend` проверяет заполнение на HTML-формах, защиту существующих значений, сопоставления, права и версии, настоящий канал расширения между двумя вкладками в изолированном профиле Edge на Windows или Chromium на Linux/CI. Все запросы к адресу ФГИС в тесте перехвачены и обслуживаются локальной фикстурой. Браузер для проверки расширения можно переопределить переменной `FGIS_TEST_BROWSER_CHANNEL` (`chrome`, `msedge`, `chromium`).

Реальная форма ФГИС, установка через пользовательскую страницу расширений и работа в Chrome/Яндекс Браузере требуют проверки на рабочем месте пользователя. Изменения интерфейса, вложенные фреймы, нестандартные справочники и страницы с недоступными полями могут потребовать настройки адаптера. Сборка ZIP выполняется автоматически перед `npm run dev` и `npm run build`.

Документация платформ: [Chrome: content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [Chrome: разрешения](https://developer.chrome.com/docs/extensions/reference/api/permissions), [Яндекс Браузер: расширения](https://browser.yandex.ru/help/ru/personalization/extension).
